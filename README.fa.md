## معرفی

ربات T.T.A برای برآورد هزینه‌های صادرات، محاسبه قیمت تمام‌شده و تهیه پیش‌فاکتور قابل ارائه به مشتری طراحی شده است. این پروژه با مدیریت **امیر شعبانیان**، بنیان‌گذار **بازرگانی شعبانیان (Shabanian Trading)** و شریک تجاری **تمنا تجارت ارمغان (T.T.A)** نگهداری می‌شود.

## امکانات

- فرایند محاسبه با متن‌های فارسی و انگلیسی
- ثبت مشخصات محصول، بسته‌بندی، تعداد و وزن خالص/ناخالص
- ثبت هزینه‌های بسته‌بندی، نیروی کار، حمل زمینی، گمرک و حمل دریایی
- ثبت روش پرداخت کرایه و نرخ‌های تبدیل ارز
- محاسبه قیمت تمام‌شده و تهیه پیش‌فاکتور PDF مشتری
- ذخیره اطلاعات کاربران و لایسنس در SQLite
- پنل مدیریت، دوره آزمایشی و مدیریت لایسنس
- فایل سرویس systemd و ابزار پشتیبان‌گیری پایگاه داده برای VPS لینوکس

## فایل‌های مهم

- `bot.py`: کد اصلی ربات
- `requirements.txt`: وابستگی‌های پایتون
- `.env.example`: نمونه متغیرهای محیطی؛ توکن واقعی را در آن قرار ندهید
- `tta-bot.service`: فایل سرویس systemd
- `scripts/install_ubuntu.sh`: نصب روی VPS اوبونتو
- `scripts/backup_db.sh`: پشتیبان‌گیری از SQLite
- `test_calculations.py`: آزمون‌های محاسبات
- `DEPLOYMENT.md`: راهنمای کامل استقرار و به‌روزرسانی در Railway و VPS

## اجرای سریع

به Python 3.10 یا بالاتر و توکن ربات از [BotFather](https://t.me/BotFather) نیاز دارید.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# فایل .env را روی سرور ویرایش کنید؛ هرگز آن را در GitHub آپلود نکنید.
python bot.py
```

حداقل متغیرهای لازم:

- `TELEGRAM_BOT_TOKEN`: توکن محرمانه ربات
- `TTA_ADMIN_IDS`: شناسه عددی تلگرام مدیر یا مدیران، با جداکننده کاما
- `TTA_DB_PATH`: مسیر پایگاه داده روی فضای ذخیره‌سازی پایدار

## استقرار در Railway

در پنل Railway متغیرها را در بخش Variables تنظیم کنید، نه در کد. فقط یک سرویس و یک نمونه polling فعال باشد. برای SQLite یک Volume پایدار متصل کنید و `TTA_DB_PATH` را به مسیری داخل mount آن تنظیم کنید؛ در غیر این صورت ممکن است اطلاعات کاربران و لایسنس‌ها با جایگزینی کانتینر از بین برود.

## استقرار روی VPS اوبونتو

راهنمای `DEPLOYMENT.md` را دنبال کنید. سرویس systemd باعث اجرای خودکار پس از راه‌اندازی مجدد سرور و بازیابی سرویس پس از خطا می‌شود. پیش از هر به‌روزرسانی از پایگاه داده پشتیبان بگیرید.

## امنیت

- هرگز `.env`، توکن تلگرام، فایل SQLite، گزارش‌ها یا اطلاعات مشتریان را در GitHub قرار ندهید.
- هم‌زمان دو نسخه از ربات را با یک توکن اجرا نکنید.
- پس از استقرار، `/start`، پنل مدیریت، یک محاسبه کامل و تولید PDF را آزمایش کنید.
