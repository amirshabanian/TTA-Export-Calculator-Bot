# Contributing

1. Open an issue describing the problem or proposed improvement without including secrets or customer data.
2. Create a feature branch and keep changes focused.
3. Run `python -m unittest -v` and manually test affected bot flows in a test bot.
4. Never include `.env`, SQLite databases, logs, customer quotations, or Telegram tokens in a pull request.
5. Describe deployment/configuration changes in `DEPLOYMENT.md`.
6. Do not claim a feature is tested unless it has actually been tested.
