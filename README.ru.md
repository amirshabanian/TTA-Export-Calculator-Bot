# 🌿 T.T.A Export Cost Calculator Bot

**Telegram-бот для расчёта экспортной себестоимости и создания коммерческих предложений в PDF**

[English](README.md) · [فارسی](README.fa.md) · [简体中文](README.zh-CN.md) · [Русский](README.ru.md) · [Türkçe](README.tr.md)

## О проекте

T.T.A Export Cost Calculator помогает экспортёрам оценивать расходы на упаковку, внутреннюю перевозку, таможню и морской фрахт, а также создавать PDF-предложения для клиентов. Проект сопровождает **Amir Shabanian**, основатель **Shabanian Trading** и деловой партнёр **Tamana Tejarat Armaghan (T.T.A)**.

## Возможности

- Диалоги на персидском и английском языках (в зависимости от текущего сценария бота)
- Данные о товаре, упаковке, количестве, весе нетто и брутто
- Расходы на упаковку, работу, внутреннюю перевозку, таможню и морской фрахт
- Способ оплаты фрахта и обменные курсы
- Расчёт себестоимости и PDF-предложение для клиента
- Данные пользователей и лицензий в SQLite
- Панель администратора, пробный период и управление лицензиями
- Шаблон systemd и скрипт резервного копирования для Ubuntu VPS

## Быстрый запуск

Требуется Python 3.10+ и токен бота, созданный через [BotFather](https://t.me/BotFather).

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python bot.py
```

Настройте `TELEGRAM_BOT_TOKEN`, `TTA_ADMIN_IDS` и `TTA_DB_PATH` через локальный `.env` или переменные среды хостинга. Никогда не загружайте токен или `.env` в GitHub.

## Развёртывание и обновление

См. [DEPLOYMENT.md](DEPLOYMENT.md) для настройки постоянного тома Railway, службы systemd на Ubuntu VPS и безопасного обновления. Для одного токена должен работать только один экземпляр long polling: не запускайте Railway и VPS одновременно.

## Безопасность

Не добавляйте в репозиторий токены, базы данных, журналы, клиентские документы или приватные ключи. Перед обновлением создавайте резервную копию SQLite. После запуска проверьте `/start`, панель администратора, полный расчёт и создание PDF.
